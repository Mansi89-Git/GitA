Q3. Write R code to load the built-in mtcars dataset. Perform basic EDA by printing its dimensions (dim()), structure (str()), and statistical summary (summary()). Also find and print the car name with maximum and minimum horsepower (hp) using which.max(), which.min() and rownames().
Ans:
# Load mtcars dataset
data(mtcars)

# Print dimensions
print(dim(mtcars))

# Print structure
print(str(mtcars))

# Print statistical summary
print(summary(mtcars))

# Find maximum horsepower
max_hp <- which.max(mtcars$hp)

# Find minimum horsepower
min_hp <- which.min(mtcars$hp)

# Print car name with maximum horsepower
print(rownames(mtcars)[max_hp])

# Print car name with minimum horsepower
print(rownames(mtcars)[min_hp])

Q4 [10 Marks]
Q4. Write an R function called calculateGrade() that accepts a vector of marks for 5 subjects, and returns the total, average, and a grade (use if-else: >=75 'A', >=60 'B', >=40 'C', else 'F'). Call the function with a sample set of marks and print the results.
Ans:
# Create function
calculateGrade <- function(marks) {
  
  # Calculate total
  total <- sum(marks)
  
  # Calculate average
  average <- mean(marks)
  
  # Calculate grade
  if (average >= 75) {
    grade <- "A"
  } else if (average >= 60) {
    grade <- "B"
  } else if (average >= 40) {
    grade <- "C"
  } else {
    grade <- "F"
  }
  
  # Return results
  return(list(
    Total = total,
    Average = average,
    Grade = grade
  ))
}

# Sample marks for 5 subjects
marks <- c(80, 75, 85, 70, 90)

# Call the function
result <- calculateGrade(marks)

# Print results
print(result)
