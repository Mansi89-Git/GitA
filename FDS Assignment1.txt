Q.3-  Scenario:  Your team needs to calculate the monthly cloud bill. You have: base compute cost ($4,200), storage cost ($780), data egress cost ($1,150), and a 12% discount coupon. Write an R script using arithmetic operators to compute the final bill after the discount. Also compute what percentage each category contributes to the pre-discount total. 
Ans:
compute_cost <- 4200
storage_cost <- 780
data_egress_cost <- 1150

discount <- 12
pre_discount_total <- compute_cost + storage_cost + data_egress_cost

discount_amount <- pre_discount_total * (discount / 100)

final_bill <- pre_discount_total - discount_amount

compute_percent <- (compute_cost / pre_discount_total) * 100
storage_percent <- (storage_cost / pre_discount_total) * 100
data_egress_percent <- (data_egress_cost / pre_discount_total) * 100

cat("Pre-discount Total: $", pre_discount_total, "\n")
cat("Discount Amount: $", discount_amount, "\n")
cat("Final Bill: $", final_bill, "\n")
cat("Compute Contribution:", round(compute_percent, 2), "%\n")
cat("Storage Contribution:", round(storage_percent, 2), "%\n")
cat("Data Egress Contribution:", round(data_egress_percent, 2), "%\n")

Q.5- Scenario:  You are writing a health-check script. Given a server's CPU usage value (input as a variable), write an R if-else chain that prints: 'Healthy' if CPU < 60%, 'Warning' if CPU is 60–85%, 'Critical' if CPU > 85%. Test your script with values 45, 72, and 91. 
Ans:
cpu_values <- c(45, 72, 91)

for (cpu in cpu_values) {
  
  cat("CPU Usage:", cpu, "% - ")
  
  if (cpu < 60) {
    print("Healthy")
  } else if (cpu >= 60 && cpu <= 85) {
    print("Warning")
  } else {
    print("Critical")
  }
}

Q.7- Your company uses a 3×3 grid of data centers (3 regions × 3 availability zones). Write a nested for loop in R to print a connectivity check table: for each region ('us', 'eu', 'ap') and each zone ('z1', 'z2', 'z3'), print 'Checking us-z1... OK' etc. Simulate one failure: 'eu-z2' should print 'TIMEOUT' instead of 'OK'. 

Ans:
regions <- c("us", "eu", "ap")
zones <- c("z1", "z2", "z3")

for (region in regions) {
  
  for (zone in zones) {
    
    if (region == "eu" && zone == "z2") {
      cat("Checking", paste(region, zone, sep = "-"), "... TIMEOUT\n")
    } else {
      cat("Checking", paste(region, zone, sep = "-"), "... OK\n")
    }
    
  }
}


Q.8-  Scenario:  Write a reusable R function called check_uptime() that takes two arguments: total_minutes (total time in a month) and downtime_minutes. The function should: calculate uptime %, print the SLA tier ('Gold' ≥ 99.9%, 'Silver' ≥ 99%, 'Bronze' ≥ 95%, 'Below SLA' otherwise), and return the uptime percentage. Test it with: (43200, 30), (43200, 300), (43200, 2500). 
Ans:

check_uptime <- function(total_minutes, downtime_minutes) {
  
    uptime_percent <- ((total_minutes - downtime_minutes) / total_minutes) * 100
  
    if (uptime_percent >= 99.9) {
    cat("SLA Tier: Gold\n")
  } else if (uptime_percent >= 99.0) {
    cat("SLA Tier: Silver\n")
  } else if (uptime_percent >= 95.0) {
    cat("SLA Tier: Bronze\n")
  } else {
    cat("SLA Tier: Below SLA\n")
  }
  
    cat("Uptime Percentage:", round(uptime_percent, 3), "%\n\n")
  
    return(uptime_percent)
}

check_uptime(43200, 30)
check_uptime(43200, 300)
check_uptime(43200, 2500)


Q.9- You collect CPU usage readings (%) every hour for 10 hours from a payment gateway server: c(45, 52, 61, 78, 85, 90, 88, 72, 63, 55). Using R vector operations: (a) find the peak CPU hour (index), (b) find all hours where CPU exceeded 75%, (c) compute the average CPU usage, (d) add a new reading of 48% for hour 11 and print the updated vector. 
Ans:
cpu_usage <- c(45, 52, 61, 78, 85, 90, 88, 72, 63, 55)

# (a) Find the peak CPU hour (index)
peak_hour <- which(cpu_usage == max(cpu_usage))

# (b) Find all hours where CPU exceeded 75%
high_cpu_hours <- which(cpu_usage > 75)

# (c) Compute the average CPU usage
average_cpu <- mean(cpu_usage)

# (d) Add a new reading of 48% for hour 11
cpu_usage <- c(cpu_usage, 48)

cat("Peak CPU Hour:", peak_hour, "\n")
cat("Hours with CPU > 75%:", high_cpu_hours, "\n")
cat("Average CPU Usage:", round(average_cpu, 2), "%\n")
cat("Updated CPU Usage Vector:\n")
print(cpu_usage)

Q.14-Scenario:  In SRE, the P95 and P99 latency are critical SLO metrics. You have response times (ms) for 20 API calls. Generate a sample using: set.seed(42); latency <- round(rnorm(20, mean=200, sd=50)). Then compute: (a) P50, P90, P95, P99 using quantile(), (b) print whether P95 exceeds your SLO threshold of 350ms, (c) visualize the distribution using a simple histogram with a title 'API Latency Distribution'. 
Ans:
set.seed(42)
latency <- round(rnorm(20, mean = 200, sd = 50))

percentiles <- quantile(latency, probs = c(0.50, 0.90, 0.95, 0.99))

cat("P50:", percentiles[1], "ms\n")
cat("P90:", percentiles[2], "ms\n")
cat("P95:", percentiles[3], "ms\n")
cat("P99:", percentiles[4], "ms\n")

if (percentiles[3] > 350) {
  cat("P95 exceeds the SLO threshold of 350 ms.\n")
} else {
  cat("P95 is within the SLO threshold of 350 ms.\n")
}

hist(latency,
     main = "API Latency Distribution",
     xlab = "Latency (ms)",
     col = "lightblue",
     border = "black")
